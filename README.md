📚 Library Management System

A simple and efficient Library Management System built using PHP, MySQL, HTML, and CSS.
This project helps manage books, readers, issuing, and returning books in a digital way.

🚀 Features

👥 Reader Management
* Register new readers with complete details (name,contact no,address)
* Edit and manage reader information

📚Book Management
* Add books with ISBN, title, author,publication year,quantity
* Search books by title, author, or publication year
* Track available copies and total number of books available in library

🛍️ Issuing Book
* Browse complete book collection
* Issue books with reader selection

🔄 Return Processing
* Process book returns with confirmation dialogs
* Reader contact information for follow-ups

🛠️ Tech Stack
* Frontend: HTML, CSS
* Backend: PHP
* Database: MySQL
* Server: XAMPP (Apache)

⚙️ Setup Instructions

1. Install XAMPP

   Start:
   * Apache
   * MySQL
  
2. Setup Project

    Copy project folder to:
    C:\xampp\htdocs\

3. Import Database
    * Open: http://localhost/phpmyadmin
    * Create database: library_db
    * Import: library_db.sql

4. Run Project

   Open browser:
  http://localhost/Library/home.php
